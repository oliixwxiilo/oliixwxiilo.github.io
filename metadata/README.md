# 插件资料填写说明

本目录保存每个插件的中文资料。每个插件对应一个 JSON 文件，文件名使用插件名称。

## 目录放置规则

- 插件图标：`assets/icons/`
- 插件截图：`assets/screenshots/插件名称/`
- 当前版本安装包：`pool/main/`
- 历史版本安装包：`pool/old/插件名称/`
- 插件中文资料：`metadata/packages/插件名称.json`

## 资料项目

每个插件可填写以下内容：

- 插件名称
- 软件包标识
- 当前版本
- 插件图标
- 插件截图（可放多张）
- 插件介绍
- 更新日志（可放多个版本）
- 旧版本下载（每个旧版本填写版本号和安装包路径）
- 支持的系统
- 安装包大小
- 上传日期

图片请使用 PNG、JPG 或 WebP。旧版本安装包请保留原始文件名，不要覆盖当前版本。
